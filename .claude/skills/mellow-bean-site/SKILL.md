# MELLOW BEAN 카페 웹페이지 가이드

회의에서 정한 결정 사항이다. 사이트를 만들거나 고칠 때 이 문서와 다르게 하려면 먼저 사용자에게 물어본다.

## 1. 컨셉

- **카페 이름**: MELLOW BEAN
- **분위기**: 미니멀 모던. 여백을 넉넉히 두고 사진을 주인공으로 둔다. 장식(그림자, 그라데이션, 아이콘 남발)은 최소화한다.
- **목적**: 카페 소개 + 메뉴를 한 페이지(스크롤형)로 보여준다.
- **대표 문구(예시)**: "부드러운 한 잔, 천천히."

## 2. 파일 구조

```
index.html        페이지 본문
css/style.css     모든 스타일
js/script.js      움직임 효과 (헤더 색 전환, 스크롤 등장)
images/           웹용 이미지 (이것만 사용)
images/originals/ 원본 보관용. 페이지에서 쓰지 않는다 (단, 아래 히어로 예외)
wedding/          이전 연습작(청첩장). 카페 사이트와 무관하니 건드리지 않는다
```

- 별도 라이브러리나 빌드 도구 없이 HTML/CSS/JS만 사용한다.
- 이미지 경로는 상대경로(`images/파일명.jpg`)로 쓴다.

## 3. 색상

CSS 변수로 `:root`에 정의하고, 색은 반드시 변수로만 사용한다.

| 변수 | 값 | 역할 |
|---|---|---|
| `--color-bg` | `#EFE8DC` | 기본 배경 (베이지) |
| `--color-text` | `#2F3E33` | 본문·제목 글자 (딥그린) |
| `--color-accent` | `#B5643C` | 버튼, 가격, 링크 강조 (테라코타) |
| `--color-sub` | `#A8B5A0` | 구분선, 보조 텍스트, 배경 포인트 (세이지) |
| `--color-white` | `#FFFFFF` | 사진 위 글자 |

- 강조색(테라코타)은 한 화면에 1~2곳만 쓴다. 많이 쓰면 미니멀한 느낌이 사라진다.
- 다크 모드는 만들지 않는다.

## 4. 글꼴

- **본문·제목**: Pretendard (CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css`)
- **로고·섹션 영문 라벨**: Pretendard 대문자 + 넓은 자간 (`letter-spacing: 0.3em`)
- 글자 크기 기준 (PC / 모바일)
  - 히어로 로고: 56px / 36px
  - 섹션 제목: 32px / 24px
  - 본문: 16px / 15px
  - 영문 라벨(MENU, SPACE 등): 13px, 대문자, 세이지 또는 딥그린
- 줄간격: 본문 1.7, 제목 1.3
- 굵기는 400(본문)과 600(제목) 두 가지만 쓴다.

## 5. 레이아웃 공통 규칙

- **반응형**: 모바일과 PC 모두 대응. 기준점은 `768px`(태블릿), `1024px`(PC).
- **콘텐츠 최대 폭**: 1200px, 가운데 정렬. 좌우 여백은 PC 40px / 모바일 20px.
- **섹션 위아래 여백**: PC 120px / 모바일 72px. 여백을 아끼지 않는다.
- **모서리**: 모두 각지게 (`border-radius: 0`). 버튼도 각지게.
- **그림자**: 사용하지 않는다.
- 가로 스크롤이 생기면 안 된다.

## 6. 섹션 구성 (위에서 아래 순서)

### 6-1. 상단 메뉴바 (Header)
- 왼쪽: `MELLOW BEAN` 로고 (대문자, 넓은 자간)
- 오른쪽: `MENU` · `SPACE` · `CONTACT` 링크 (같은 페이지의 섹션으로 이동)
- 히어로 위에서는 투명 배경 + 흰 글자. 스크롤해서 내려가면 베이지 배경 + 딥그린 글자로 바뀐다.
- 모바일에서도 링크 3개를 작게 그대로 보여준다 (햄버거 메뉴 사용 안 함).

### 6-2. 첫 화면 (Hero)
- **화면 전체 높이**(`100vh`)를 사진으로 채운다.
- 사진: `images/originals/hand-drip-coffee.jpg` (1280px, 큰 화면에서 흐려지지 않도록 히어로만 원본 사용)
- `object-fit: cover`로 화면 비율에 맞게 자른다.
- 사진 위에 반투명 어두운 막(`rgba(0,0,0,0.35)`)을 깔아 글자가 잘 읽히게 한다.
- 가운데에 흰 글자로: 로고 `MELLOW BEAN` → 대표 문구 → `메뉴 보기` 버튼(흰 테두리, 각진 모서리, 메뉴 섹션으로 이동)

### 6-3. 메뉴 (Menu)
- 라벨 `MENU` + 제목 "오늘의 한 잔"
- **사진 카드 격자**: PC 3열, 태블릿 2열, 모바일 1열. 카드 간격 PC 32px / 모바일 20px.
- 카드 구성: 사진 → 메뉴 이름 → 짧은 설명 1줄 → 가격(테라코타색)
- 사진은 모두 같은 비율(`aspect-ratio: 4 / 5`)로 맞추고 `object-fit: cover`로 자른다. 원본 사진들의 비율이 제각각이라 꼭 필요하다.
- 메뉴 데이터 (예시 내용, 사용자가 나중에 바꿀 수 있음):

| 이미지 | 이름 | 설명 | 가격 |
|---|---|---|---|
| `cafe-latte.jpg` | 카페 라떼 | 고소한 우유와 에스프레소의 균형 | 5,500 |
| `latte-with-cookie.jpg` | 라떼 & 쿠키 세트 | 따뜻한 라떼와 수제 초코칩 쿠키 | 7,500 |
| `hand-drip-coffee.jpg` | 핸드드립 커피 | 한 잔씩 천천히 내리는 싱글 오리진 | 6,500 |
| `lemon-ade.jpg` | 레몬 에이드 | 직접 담근 레몬청으로 만든 상큼한 에이드 | 6,000 |
| `strawberry-latte.jpg` | 딸기 라떼 | 생딸기를 갈아 넣은 부드러운 라떼 | 6,500 |
| `tiramisu.jpg` | 티라미수 | 마스카포네 크림과 진한 초콜릿 | 7,000 |

- 가격 표기: `5,500원`

### 6-4. 공간 (Space)
- 라벨 `SPACE` + 제목 "머물고 싶은 공간"
- 사진: `images/cafe-interior.jpg`를 **콘텐츠 최대 폭 전체**로 크게 보여준다. 매장 분위기를 전달하는 것이 이 섹션의 목적이다.
- 사진 아래에 짧은 소개 글 2~3줄 (예시: "높은 천장과 커다란 창, 초록 식물 사이에서 커피 한 잔의 여유를 즐겨보세요. 매장 안쪽에서는 매일 아침 원두를 직접 로스팅합니다.")
- 배경은 세이지(`--color-sub`)를 아주 옅게 쓰거나 기본 베이지 그대로 둔다.

### 6-5. 연락처 (Contact / Footer)
- 배경 딥그린(`--color-text`), 글자 베이지(`--color-bg`) — 페이지 마무리를 색으로 구분한다.
- 내용 (예시):
  - 주소: 대구광역시 중구 ○○로 123, 반월당역 도보 5분 (예시 주소)
  - 영업시간: 매일 10:00 – 21:00 (라스트 오더 20:30)
  - 전화: 02-000-0000
  - 인스타그램: @mellowbean (예시)
- **배치 (태블릿·PC)**: 왼쪽 칸에 글자 정보, 오른쪽 칸에 지도(`images/cafe-map.png`)를 둔다.
  - 왼쪽: 라벨 → 로고 → 문구 → 연락처 항목. 항목은 한 줄에 "이름 + 내용"으로 위에서 아래로 쌓는다.
  - 오른쪽: 지도 높이는 왼쪽 글자 칸 높이와 똑같이 맞춘다 (`object-fit: cover`). 푸터가 지도 때문에 길어지면 안 된다.
  - 지도가 잘려도 빨간 원이 보이도록 `object-position: 58% 41%`를 유지한다.
- **배치 (모바일)**: 글자 정보 아래에 지도를 4:3 비율로 둔다.
- 맨 아래 작은 글씨: `© 2026 MELLOW BEAN`

## 7. 움직임 효과 (은은하게)

- **스크롤 등장**: 각 섹션과 메뉴 카드가 화면에 들어올 때 아래에서 20px 올라오며 투명도 0→1 (0.6초). `IntersectionObserver` 사용.
- **메뉴 카드 hover**: 사진만 살짝 확대(`scale(1.04)`, 0.4초). 카드 밖으로 넘치지 않게 `overflow: hidden`.
- **헤더**: 배경색 전환 0.3초.
- 링크 클릭 시 부드러운 스크롤 (`scroll-behavior: smooth`).
- 사용자가 OS에서 움직임 줄이기를 켰다면(`prefers-reduced-motion`) 모든 애니메이션을 끈다.
- 이 외의 효과(패럴랙스, 글자 타이핑, 슬라이더 등)는 넣지 않는다.

## 7-1. 반응형 세부 규칙

| 항목 | 모바일 (~767px) | 태블릿 (768~1023px) | PC (1024px~) |
|---|---|---|---|
| 히어로 로고 | 화면 폭에 맞춰 24~36px | 44px | 56px |
| 섹션 제목 | 24px | 28px | 32px |
| 메뉴 격자 | 1열, 사진 1:1 | 2열, 사진 4:5 | 3열, 사진 4:5 |
| 푸터 | 글자 아래 지도 (4:3) | 좌 글자 / 우 지도 | 좌 글자 / 우 지도 |
| 연락처 보조 정보 | 다음 줄에 표시 | 다음 줄에 표시 | 같은 줄 괄호 안 |

- 메뉴 사진 확대 효과는 마우스가 있는 기기(`@media (hover: hover)`)에서만 쓴다.
- 상단 메뉴 링크는 위아래 여백으로 터치 영역을 넉넉히 둔다.
- 320px(작은 휴대폰)에서도 헤더 링크 3개가 한 줄에 들어가야 한다.

## 8. 이미지 사용 규칙

- 모든 `<img>`에 한글 `alt`를 쓴다 (예: `alt="유리잔에 담긴 카페 라떼"`).
- 히어로를 제외한 이미지에는 `loading="lazy"`를 붙인다.
- 새 이미지를 추가할 때는 영문 소문자-하이픈 이름으로 `images/`에 넣고, 긴 변 1000px 이하로 줄이고, 원본은 `images/originals/`에 보관한다.

## 9. 완성 후 체크리스트

- [ ] PC(1440px), 태블릿(1024px, 768px), 모바일(375px, 320px) 폭에서 모두 깨지지 않는다
- [ ] 가로 스크롤이 생기지 않는다
- [ ] 히어로 사진 위 글자가 잘 읽힌다
- [ ] 메뉴 카드 사진 비율이 모두 같다
- [ ] 헤더 링크를 누르면 해당 섹션으로 부드럽게 이동한다
- [ ] 색은 모두 CSS 변수로만 쓰였다
- [ ] 모든 이미지에 alt가 있다
